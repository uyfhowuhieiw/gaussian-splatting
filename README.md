# 高斯泼溅 · 给学美术的人看的三维新玩具

> Gaussian Splatting 通俗科普页 —— 用**看得见、转得动**的方式讲清楚它是什么。
> 单文件 HTML，零外部依赖，美术、音效、三维演示全部由代码实时生成。

## 它讲了什么

| 章节 | 内容 |
|---|---|
| 一句话 | 把三维空间当画布，往里喷几百万个软边彩色笔触，让它们自己融成实物 |
| 先看区别 | 传统三角网格 vs 高斯泼溅，左右对比 |
| 亲手玩 | 实时 3D 泼溅渲染：拖拽旋转、调光斑数量、换形状 |
| 三步流程 | 拍一圈照片 → 电脑撒点 → 反复改（哪儿不像就调哪几颗球） |
| 每颗球四件事 | 我在哪 / 我多大 / 我什么颜色 / 我多透明 |
| 对比表 | 传统网格 / NeRF / 高斯泼溅 |
| 术语表 | Splat、高斯、点云、COLMAP、训练、加密与修剪 |
| 工具推荐 | Luma AI、Postshot、SuperSplat、Blender 插件、引擎插件 |
| 局限性 | 文件大、幽灵漂浮物、光被焊死、不好做动画、镜面翻车、不是模型 |

## 最值得玩的一处

交互区里**光斑大小是固定的，只有数量会变**：

- 调到 **300** → 一个个独立可辨的软边椭圆，能看到掠射角把椭圆压扁
- 拉到 **9000** → 自动融合成有体积的实心环面

这是理解「几百万个光斑怎么变成实物」最直观的一步。

## 技术实现

页面里所有三维演示都是**实时算出来的**，不是视频也不是图片：

```
三维高斯球 → 按视角旋转 → 透视投影 → 按深度排序 → 半透明 alpha 叠加
```

- Canvas 2D 实现，用「单位径向渐变 + 逐球 translate/scale」模拟椭球投影
- 掠射角越大椭圆压得越扁，近似真实 3DGS 的协方差投影
- 径向渐变只在颜色变化时创建一次并缓存，避免每帧新建上万个渐变

> 说明：真实 3DGS 用的是三维协方差矩阵投影出的二维椭圆；本页用圆形径向渐变近似，
> 原理一致但便于在浏览器里流畅运行。

## 附带的 URL 参数

| 参数 | 作用 |
|---|---|
| `?static=1` | 冻结动画，只渲染一帧（截图、做分享图用） |
| `?focus=cvPlay` | 只显示某个区块（配合 static 出图） |
| `?shape=heart` | 指定初始形状：`torus` / `sphere` / `heart` |
| `?n=12000` | 指定初始光斑数量：300 ~ 20000 |

例如只显示爱心、12000 个光斑：`?static=1&focus=cvPlay&shape=heart&n=12000`

## 写在最后

而你对光影、颜色、质感的判断力，在挑选、清理、调整泼溅结果的时候，恰恰是最值钱的。
